The product data is still the placeholder registry compiled into the image
(doc-portal/src/lib/products.ts), so a change to it needs a rebuild, not a
restart. Only the addresses above are configuration.

Reminder: image.tag is pinned with pullPolicy: Never in values-local.yaml, so a
rebuilt image under the same tag leaves the running pods untouched. After
rebuilding, force them over:
  kubectl rollout restart deployment/{{ include "doc-portal.fullname" . }} -n {{ .Release.Namespace }}

or just run helm/doc-portal/deploy.sh, which does all three steps.
